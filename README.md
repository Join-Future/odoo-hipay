# HiPay by Join Future for Odoo

Odoo payment provider for HiPay by Join Future: cards, BENEFIT, Apple Pay and
Google Pay for Odoo in Bahrain and the GCC.

The module is in [`payment_joinfuture_hipay/`](payment_joinfuture_hipay/). See
[`payment_joinfuture_hipay/README.md`](payment_joinfuture_hipay/README.md) for installation and setup.

Branch `18.0` is for Odoo 18. Licensed under LGPL-3.
